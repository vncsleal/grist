---
title: Quickstart
description: First-run tutorial — from install to your first draft
order: 3
---

1. Install Quillby using one of the methods on the [install page](/docs/install).
2. Restart Claude Desktop.
3. Say: **"Set me up with Quillby"**
4. Answer the onboarding questions about your role, industry, and audience.
5. Quillby discovers feeds automatically. Say: **"What should I post today?"**
