---
title: Instalação
description: Instale o Quillby no macOS, Windows ou Linux
order: 1
---

## macOS

Download the `.pkg` installer from [GitHub Releases](https://github.com/vncsleal/quillby/releases/latest).

Or install via terminal:
```bash
curl -fsSL https://raw.githubusercontent.com/vncsleal/quillby/main/install.sh | bash
```

## Windows

Download the installer from [GitHub Releases](https://github.com/vncsleal/quillby/releases/latest).

Or install via PowerShell:
```powershell
irm https://raw.githubusercontent.com/vncsleal/quillby/main/install.ps1 | iex
```

## Linux / npm

```bash
npm install -g @vncsleal/quillby
```
