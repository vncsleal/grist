## O Cloud mode está sendo preparado

O Quillby Cloud vai oferecer tudo que o modo Local já faz, mas hospedado — sem precisar instalar nada no seu computador.

**O que vem por aí:**

- Acesse de qualquer dispositivo
- Convide sua equipe para workspaces compartilhados
- Dashboard web para gerenciar workspaces e revisar rascunhos
- Suporte prioritário

Enquanto isso, o **modo Local** já está disponível e funciona perfeitamente. Instale agora e comece a usar.
